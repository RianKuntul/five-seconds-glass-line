Entry for make.fun's **Five Seconds to Explain the Glass**
(`u-po-pu-five-seconds-to-explain-the-glass-934d9949`, $2 prize).

`main.ts` (Node 22, no dependencies) writes one original sentence — the
excuse a house cat gives in the five seconds after sweeping a glass off the
table — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the
variable is unset). The line is a fixed string in the source: deterministic,
no network, no randomness, no trailing newline. One sentence, under 200
characters, in the cat's own voice: no apology, no confession, just the most
convincing case a cat can make for itself.

Run it:

```sh
node main.ts
```
